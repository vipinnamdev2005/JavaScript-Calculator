# JavaScript Calculator

## About the Project
This is a simple interactive calculator developed using HTML, CSS, and JavaScript.

It allows users to perform basic mathematical operations through an easy-to-use interface.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Backspace functionality
- Clear (C) functionality
- Equal (=) button to calculate results

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the calculator in your browser.
2. Click the number buttons to enter numbers.
3. Select an arithmetic operator.
4. Enter another number.
5. Click the equals (=) button to see the result.
6. Use C to clear the screen.
7. Use the backspace button to remove the last character.
